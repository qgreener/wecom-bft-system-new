# 15-前端架构与设计系统落地规范

## 1. 文档定位

| 项目 | 说明 |
|---|---|
| 文档目标 | 为新系统 PC 管理端、小程序端、企微侧边栏 H5、供货商 H5 和公开留资 H5 提供统一前端架构、视觉语言、组件复用和页面模板落地规范 |

## 2. 前端整体风格定位

### 2.1 风格关键词

| 端侧 | 风格定位 | 设计目标 | 避免事项 |
|---|---|---|---|
| PC 管理端 | 专业、清晰、可信、高信息密度后台 | 让运营、教务、客服、仓管、代账在列表、筛选、详情和待办之间高效处理业务 | 过度营销化、大面积装饰背景、低信息密度卡片堆叠、颜色含义混乱 |
| 小程序端 | 轻量、清楚、路径短 | 让学员快速完成课程浏览、下单支付、学习、退款、发票、地址和物流查询 | 后台化表格、过多筛选项、弱化主操作、关键状态不可见 |
| 企微侧边栏 H5 | 窄屏、即时、辅助沟通 | 让运营在企微聊天上下文中快速识别客户、创建线索、写跟进、查看摘要 | 重型后台布局、长流程跳转、需要横向滚动的信息表 |
| 供货商 H5 | 窄屏、任务明确、可提交 | 让供货商围绕采购单完成确认、拒绝、物流和进项发票回填 | 暴露 PC 管理能力、展示其他供货商数据、复杂多级菜单 |
| 公开留资 H5 | 简洁、可信、低摩擦 | 让外部潜客快速提交姓名、手机号和意向课程 | 大段宣传内容、过多字段、提交后无明确反馈 |

### 2.2 视觉系统基调

| 维度 | PC 管理端 | 小程序 / H5 |
|---|---|---|
| 主色 | 建议使用深蓝或企业蓝作为主色，用于主按钮、选中菜单、关键链接 | 延续主色，但降低面积，用于底部导航选中态、主按钮和关键价格 |
| 中性色 | 以白色内容面、浅灰页面背景、深灰正文为主，突出信息层级 | 页面背景浅灰，内容卡片白底，正文高对比 |
| 功能色 | 成功绿色、警示橙色、错误红色、处理中蓝色、禁用灰色 | 与 PC 同源，但标签更轻，避免整页强色块 |
| 字体 | 系统默认无衬线字体，数字金额使用等宽或 tabular figures | 系统默认字体，移动端正文不小于 14px，关键金额不小于 18px |
| 圆角 | 后台控件建议 4px 到 8px；卡片不超过 8px | 移动端卡片 8px，按钮可 8px 到 12px，但保持克制 |
| 阴影 | PC 只在弹窗、抽屉、顶部悬浮和少量卡片使用浅阴影 | H5 和小程序用细边框或轻阴影区分卡片，不做装饰性大阴影 |
| 图标 | 使用统一线性图标库，图标尺寸按令牌管理 | 小程序可使用微信生态图标或统一矢量图标，不使用 emoji 作为结构图标 |

### 2.3 设计令牌建议

| 类型 | Token | 建议值或规则 | 使用范围 |
|---|---|---|---|
| 间距 | `space-4`、`space-8`、`space-12`、`space-16`、`space-24`、`space-32` | 以 4px / 8px 为节奏 | 表单项、筛选区、卡片、列表、页面留白 |
| 字号 | `font-12`、`font-14`、`font-16`、`font-18`、`font-20`、`font-24` | PC 表格可用 13px 到 14px；移动端正文不低于 14px | 正文、表头、标题、金额 |
| 行高 | `line-tight`、`line-normal`、`line-relaxed` | 1.4 / 1.5 / 1.7 | 表格、表单、长文本 |
| 圆角 | `radius-4`、`radius-6`、`radius-8`、`radius-12` | PC 默认 4px 或 6px，移动卡片默认 8px | 输入框、按钮、标签、卡片、弹窗 |
| 边框 | `border-subtle`、`border-strong` | 浅灰分割线，重要区域可加深 | 表格、卡片、详情区块 |
| 层级 | `z-header`、`z-sidebar`、`z-drawer`、`z-modal`、`z-toast` | 顶栏 < 抽屉 < 弹窗 < 消息提示 | 固定栏、抽屉、弹窗、Toast |
| 动效 | `motion-fast`、`motion-normal` | 150ms 到 300ms，使用 opacity / transform | 菜单展开、抽屉进入、弹窗、按钮反馈 |

## 3. 前端架构落地规范

### 3.1 端侧工程边界

| 端侧 | 推荐路径 | 技术栈 | 职责边界 |
|---|---|---|---|
| PC 管理端 | `frontend/admin/` | Vue 3 + TypeScript + Vite + Element Plus 或 Ant Design Vue | 承载后台菜单、列表、详情、审批、退款、发货、开票、对账、配置和审计 |
| 小程序端 | `frontend/miniprogram/` | 微信小程序原生 + TypeScript，或 uni-app Vue3 | 承载微信登录、手机号授权、课程、下单支付、学习、退款、发票、地址和物流 |
| 企微侧边栏 H5 | `frontend/h5/wecom-sidebar/` | Vue 3 + TypeScript + Vite | 依赖企微 JS-SDK 上下文，展示客户识别、线索、学员和订单摘要 |
| 供货商 H5 | `frontend/h5/supplier/` | Vue 3 + TypeScript + Vite | 只处理当前供货商自身采购单，不进入 PC 权限体系 |
| 公开留资 H5 | `frontend/h5/lead/` | Vue 3 或轻量静态 H5 | 匿名留资、来源码、手机号校验和提交反馈 |
| 共享前端包 | `frontend/shared/` | TypeScript | API 类型、枚举展示、状态标签配置、权限工具、金额日期格式化、上传客户端 |

### 3.2 分层职责

| 分层 | PC / H5 建议目录 | 小程序建议目录 | 职责 | 约束 |
|---|---|---|---|---|
| 应用层 | `app/` | `app.ts`、`app.json` | 初始化插件、错误处理、请求上下文、环境配置 | 不写业务页面逻辑 |
| 页面层 | `views/` | `pages/` | 组织路由页面、调用服务、组合组件 | 页面只编排，不复制复杂业务组件 |
| 组件层 | `components/` | `components/` | 通用表格、状态标签、表单区块、上传、步骤条、单据链 | 组件用 props 和 slots 表达差异，不按页面复制 |
| 组合逻辑 | `composables/` | `hooks/` 或 `utils/` | 分页、筛选、权限、幂等键、上传、TraceId | 命名使用 `useXxx` |
| 服务层 | `services/` | `services/` | API 客户端、请求拦截、统一响应、错误码映射 | 写操作统一带 `Idempotency-Key` |
| 状态层 | `stores/` | `stores/` | 登录态、权限、枚举字典、系统配置缓存 | 业务事实以后端返回为准 |
| 类型层 | `types/` | `types/` | OpenAPI 生成类型和前端扩展类型 | 不重复定义后端枚举编码 |
| 工具层 | `utils/` | `utils/` | 金额、日期、脱敏、文件大小、列表空值展示 | 金额仅做分转元展示，不用浮点参与计算 |

### 3.3 共享能力优先级

| 优先级 | 能力 | 说明 |
|---|---|---|
| P0 | API 客户端、统一响应处理、枚举字典、权限工具、金额日期格式化 | 三端联调和页面一致性的基础 |
| P0 | 状态标签、筛选表单、数据表格、详情描述、文件上传、空状态、异常提示 | PC 和 H5 高频复用 |
| P0 | 订单单据链组件 | 订单详情、学员详情、退款详情、开票详情、对账追溯共用 |
| P1 | 页面模板生成器或配置化表格列 | 降低后台列表页重复成本 |
| P1 | 导出、文件预览、打印、面单下载 | 发票、退款、对账、发货、代账材料复用 |
| P1 | 埋点和审计提示组件 | 敏感操作前提示、操作后展示 trace_id |

## 4. PC 管理端布局规范

### 4.1 全局布局

| 区域 | 规范 | 交互规则 |
|---|---|---|
| 侧边栏 | 固定左侧，宽度建议 220px，可折叠到 64px；深色背景；一级菜单和二级菜单按权限返回渲染 | 菜单来自 `/api/admin/auth/me.menus[]`，无权限菜单不渲染；折叠后保留图标和 Tooltip |
| 顶部栏 | 高度建议 56px 到 64px；包含面包屑、当前用户、角色、退出入口 | 用户信息来自登录态；异常或无角色时进入角色申请页 |
| 面包屑 | 首页 / 一级菜单 / 二级页面 / 当前对象编号 | 列表到详情必须保留返回路径；企微卡片跳转进入详情时也应显示业务路径 |
| 内容区 | 浅灰背景，内部白色内容面；页面左右留白 16px 到 24px | 主要操作优先放在内容面右上；批量操作放在表格上方 |
| 页面标题区 | 标题 + 状态摘要 + 主操作 | 详情页标题右侧展示四类状态标签或关键业务状态 |
| 固定操作栏 | 长表单或详情审核页使用底部固定操作栏 | 固定栏必须给内容区预留底部间距，避免遮挡 |

### 4.2 侧边栏规范

| 项目 | 规范 |
|---|---|
| 一级菜单 | 首页、客户与学员、课程与履约、供应与库存、交易售后、财税与报表、系统配置 |
| 二级菜单 | 按 03 模块映射和 08 权限矩阵渲染，用户无权限时不出现 |
| 默认展开 | 当前路由所在一级菜单展开；系统配置默认收纳低频项 |
| 计数徽标 | 待办数可显示在菜单右侧，例如待审核退款、待发货、待开票、库存预警 |
| 角色差异 | 讲师、仓管、代账等角色只展示本角色相关入口，不展示置灰的无权限菜单 |
| 视觉状态 | 选中态使用主色背景或左侧色条，悬停态只轻微提亮 |

### 4.3 顶部栏与面包屑

| 元素 | 展示规则 |
|---|---|
| 面包屑 | 列表页显示到二级菜单；详情页追加业务对象，如 `订单详情 / ORDER_NO` |
| 用户区 | 展示头像或姓名首字、显示名、角色；多角色时可展示当前角色标签 |
| 全局提醒 | 可放未读通知、异常待办入口；不替代首页流程看板 |
| 退出 | 放在用户下拉菜单中，避免误触 |
| TraceId | 业务错误弹窗和接口错误详情可展示 `trace_id` 供联调排查 |

### 4.4 内容区、筛选区和表格

| 组件 | 规范 | 适用页面 |
|---|---|---|
| 筛选区 | 位于表格上方，白底，字段横向排列；超过一行时使用“展开更多” | 线索、课程、订单、退款、开票、发货、采购、对账、日志 |
| 筛选字段 | 高频字段默认展示；低频字段折叠；日期范围放首位或靠前 | 订单日期、状态筛选、关键字搜索 |
| 操作按钮 | 主操作放筛选区右侧，如新增课程、新建采购单、上传结算单 | 新建、上传、导出、同步供货商 |
| 表格密度 | PC 默认中等偏紧凑；行高 44px 到 52px；金额和状态列固定宽度 | 高信息密度后台 |
| 表格列 | 优先固定业务编号、对象摘要、状态、时间、操作；长文本省略并 Tooltip | 订单、退款、发货、采购、对账 |
| 行操作 | 不超过 3 个直接按钮；更多动作收纳进下拉菜单 | 审核、查看、重试、红冲 |
| 分页 | PC 使用页码分页，默认每页 20；移动端使用上拉加载 | 所有管理列表 |

### 4.5 详情页规范

| 区块 | 规范 | 示例 |
|---|---|---|
| 标题摘要 | 左侧业务标题和编号，右侧状态标签组 | 订单详情右侧展示支付、履约、退款、开票 |
| 状态概览 | 使用 2 到 4 个摘要卡片或状态标签行，不合并为单一状态 | 订单四类状态、退款步骤、采购状态 |
| 基础信息 | 使用描述列表，按业务、人员、时间、金额分组 | 订单信息、学员信息、采购信息 |
| 明细信息 | 表格或卡片列表承载商品、规格、SKU、文件、日志 | 订单商品、采购商品、税额拆分 |
| 单据链 | 独立区块，按时间线或卡片展示关联单据 | 支付、权益、发货、退款、发票、对账、代账材料 |
| 操作区 | 底部固定或标题右侧；只展示当前状态和权限允许的动作 | 确认发货、审核退款、人工开票 |
| 审计信息 | 敏感操作页展示操作记录或日志入口 | 退款审核、人工退款、开票红冲 |

### 4.6 弹窗与抽屉

| 类型 | 使用场景 | 规范 |
|---|---|---|
| 小弹窗 | 确认、单字段输入、拒绝原因、简单审核 | 宽度 420px 到 560px，主操作在右下，危险操作使用红色 |
| 中弹窗 | 跟进记录、发货、人工退款、手动开票、上传文件 | 宽度 640px 到 800px，表单字段分组，提交中按钮 loading |
| 大弹窗 | 推广码管理、出入库记录、物流轨迹预览 | 宽度不超过视口 80%，内容滚动只在弹窗内部 |
| 抽屉 | 不离开列表查看详情、补充材料、查看差异 | 右侧滑出，宽度 480px 到 720px；保留关闭和返回 |
| 二次确认 | 删除、红冲、取消采购、关闭材料、导出敏感文件 | 文案必须说明影响范围和不可逆风险，必要时填写原因 |

## 5. 小程序端页面规范

### 5.1 全局移动规范

| 项目 | 规范 |
|---|---|
| 导航 | 底部三栏：课程、我的、学习中心；次级页面左上返回 |
| 页面宽度 | 不出现横向滚动；内容使用 16px 左右安全边距 |
| 触控 | 主要点击区域不小于 44px；列表卡片整块可点击但操作按钮需分离 |
| 固定栏 | 购买、提交订单、保存地址、申请退款等主操作固定底部 |
| 信息密度 | 移动端使用卡片和分组，不使用 PC 表格；状态标签最多两行，超出折叠 |
| 反馈 | 提交成功使用 Toast 或结果页；异步支付、退款、开票以服务端最新状态为准 |

### 5.2 课程页面

| 页面 | 核心组件 | 展示规范 | 操作规范 |
|---|---|---|---|
| 课程列表 | 搜索框、类型分段控件、课程卡片、加载更多 | 卡片左图右文，展示课程名、最低价格、直播/录制标签 | 搜索和类型筛选即时刷新；点击卡片进入详情 |
| 课程详情 | 课程详情、规格选择、课程安排折叠、底部购买栏 | 规格用可点击列表或轻表格；选中规格同步价格；赠品单独提示 | 点击购买前校验登录和手机号授权；未授权先拉起授权 |
| 课程学习 | 播放器、章节折叠、直播倒计时、课程群二维码 | 未开播显示倒计时；录播显示回放；二维码可放大 | 权益非 `ACTIVE` 时隐藏学习入口并提示原因 |
| 学习中心 | 类型分段、已购课程卡片、进入学习按钮 | 待删除课程展示倒计时和通知入口 | 点击进入学习前重新校验权益状态 |

### 5.3 订单页面

| 页面 | 核心组件 | 展示规范 | 操作规范 |
|---|---|---|---|
| 订单确认 | 课程摘要、地址选择、商品明细、金额汇总、底部提交栏 | 含实物才显示地址；金额统一由后端确认结果展示 | 先调用订单确认接口，提交订单必须带幂等键 |
| 支付成功 | 结果图标、订单编号、权益提示、双按钮 | 若含实物展示待发货提示 | “去学习”进入课程学习，“查看订单”进入订单详情 |
| 我的订单 | 状态筛选、订单卡片、倒计时、继续支付 | 卡片展示四类状态标签，金额右对齐突出 | 待支付且未超时显示继续支付；列表上拉加载更多 |
| 订单详情 | 状态概览、课程信息、金额、物流、订单信息、底部操作栏 | 四类状态必须同时可见，不能合并成一个订单状态 | 动作按后端返回状态和权限展示，退款中阻止新开票 |

### 5.4 退款页面

| 页面 | 核心组件 | 展示规范 | 操作规范 |
|---|---|---|---|
| 退款申请 | 订单摘要、原因选择、补充说明、提交按钮 | 退款原因必选，说明限制 200 字 | 提交创建退款单，订单支付状态保持已支付 |

## 7. 状态标签规范

### 7.1 标签设计规则

| 规则 | 说明 |
|---|---|
| 编码来源 | 标签编码来自接口枚举或后端字典，不在页面手写散落的状态文案 |
| 展示结构 | 标签包含中文文案、语义色、可选图标、可选 Tooltip |
| 颜色语义 | 蓝色表示进行中或已受理，绿色表示成功终态，橙色表示待处理或警示，红色表示失败/拒绝/高风险，灰色表示无、关闭、取消 |
| 信息表达 | 关键状态不能只靠颜色，必须有文字；异常状态补充失败原因入口 |
| 订单页面 | 必须同时展示支付、履约、退款、开票四类标签，不得合并为单一订单状态 |
| 移动端 | 标签可换行，但不得遮挡金额、按钮和关键时间 |

## 9. 通用组件规范

### 9.1 表格

| 项目 | 规范 |
|---|---|
| 列配置 | 业务编号、对象摘要、状态、金额、时间、操作为常用列；列配置尽量可复用 |
| 状态列 | 使用统一 `StatusTag`，不得每个页面单独写颜色 |
| 金额列 | 右对齐，展示元格式，原始值仍来自 `_cent` 字段 |
| 时间列 | 使用统一格式，PC 精确到分钟或秒，移动端可显示日期和时间两行 |
| 空值 | 使用 `-`，不展示 `null`、`undefined`、空数组文本 |
| 行高 | 管理端 44px 到 52px；包含多行摘要时不超过 72px |
| 操作列 | 固定右侧；危险动作进入二次确认 |
| 导出 | 导出按钮必须按权限显示，导出字段按角色裁剪并写审计 |

### 9.2 表单

| 项目 | 规范 |
|---|---|
| 标签 | 必须有可见标签，不使用占位符替代标签 |
| 必填 | 必填项用星号或明确文案标记；提交前和失焦后校验 |
| 错误 | 错误提示显示在字段下方，说明原因和修复方式 |
| 分组 | 长表单按基本信息、业务信息、文件、备注分组 |
| 提交 | 提交按钮 loading 并防重复；写操作统一生成或传入 `Idempotency-Key` |
| 只读 | 详情页和无权限字段使用只读态，不用禁用态伪装 |
| 原因 | 拒绝、取消、红冲、关闭、人工处理等动作必须填写原因或备注 |

### 9.3 步骤条

| 类型 | 使用场景 | 规范 |
|---|---|---|
| 退款步骤 | 小程序退款进度、PC 退款详情 | 审核中、已拒绝、退款处理中、待人工退款、退款失败、已退款按实际状态高亮 |
| 物流步骤 | 物流详情 | 已揽收、运输中、派送中、已签收；轨迹节点补充详细时间 |
| 采购步骤 | 采购详情 | 审批、待确认、已确认、已发货、已完成；拒绝和取消作为分支状态 |
| 开票步骤 | 发票详情 | 已申请、待开具、已开具、已红冲；红冲不等于退款 |

### 9.4 上传

| 项目 | 规范 |
|---|---|
| 入口 | 统一走后端文件上传接口；直传也必须由后端签发临时授权 |
| 文件类型 | 按业务限制图片、PDF、Excel/CSV；前端校验不替代后端校验 |
| 展示 | 上传后展示文件名、大小、状态、预览或下载入口 |
| 幂等 | 使用 `file_digest + biz_type + biz_id` 防重复绑定 |
| 鉴权 | 下载和预览都走受控地址，按角色、数据范围和业务对象校验 |
| 失败 | 失败展示原因和重试入口；不要只显示“上传失败” |

### 9.5 异常提示

| 场景 | 展示规范 |
|---|---|
| 参数错误 | 字段下方提示，表单顶部可汇总 |
| 未登录 | 跳转登录或授权页，保留回跳地址 |
| 无权限 | 页面级显示无权限说明；按钮级无权限不渲染或禁用并显示 Tooltip |
| 状态冲突 | 弹窗说明当前最新状态，提供刷新入口 |
| 幂等冲突 | 提示重复提交或请求已处理，必要时跳转到已创建对象 |
| 外部失败 | 展示平台或适配失败摘要、失败原因、trace_id 和可处理动作 |
| 网络超时 | 提供重试，不假定业务失败；写操作优先查询结果再提示 |

### 9.6 空状态与加载态

| 类型 | 规范 |
|---|---|
| 首屏加载 | PC 表格使用骨架或局部 loading；移动端使用骨架卡片 |
| 局部刷新 | 筛选和分页只刷新列表区域，不闪烁整个页面 |
| 空列表 | 展示当前筛选下无数据，并提供清空筛选或新建入口 |
| 无权限空态 | 明确说明当前角色无权访问，不提供误导性新建按钮 |
| 异常空态 | 展示失败原因和重试按钮；保留 trace_id |
| 长任务 | 导入、导出、对账、开票等异步任务展示处理中状态和刷新入口 |

## 10. 权限控制在前端的展示规则

### 10.1 权限数据来源

| 数据 | 来源 | 前端用途 |
|---|---|---|
| `roles[]` | `/api/admin/auth/me` | 展示当前角色、判断角色提示文案 |

| `data_scope` | `/api/admin/auth/me` | 展示当前数据范围说明，不在前端自行过滤业务数据 |
| `field_masks[]` | `/api/admin/auth/me` | 控制手机号、地址、税号、流水号、文件等字段脱敏 |
| `allowed_actions[]` | 业务详情或侧边栏上下文接口 | 控制当前对象在当前状态下可执行动作 |

### 10.2 展示规则

| 场景 | 前端规则 | 后端规则 |
|---|---|---|
| 菜单无权限 | 不渲染菜单和路由入口 | 接口仍返回 `403` 或过滤资源 |
| 按钮无权限 | 默认不渲染；需要解释时禁用并 Tooltip | 写接口必须校验按钮权限、状态机和幂等 |
| 数据范围不足 | 列表由后端过滤；前端可显示“仅展示本人负责范围” | 查询统一注入数据范围 |
| 字段脱敏 | 按 `field_masks[]` 使用统一脱敏组件 | 后端返回已脱敏值或字段掩码 |
| 导出权限 | 无权限不展示导出；有权限导出前二次确认 | 导出按字段裁剪并写审计 |
| 文件下载 | 无权限不展示下载，或点击后提示无权 | 下载接口校验角色、数据范围、业务对象 |
| 状态动作 | 同时满足权限和 `allowed_actions[]` 才展示 | 后端状态机做最终裁决 |
| 企微侧边栏 | 按企微上下文和内部身份展示 | 校验企微签名、内部登录态、运营数据范围 |
| 供货商 H5 | 只展示当前供货商采购单 | 令牌校验后按 `supplier_id` 强制过滤 |

### 10.3 角色差异重点

| 角色 | 前端展示重点 |
|---|---|
| 超级管理员 | 全菜单、角色审批、系统配置、操作日志、敏感操作二次确认 |
| 教务 | 课程管理和课程编辑为主；客户、订单、财税以只读摘要为主 |
| 讲师 | 只展示负责课程内容、直播、回放和负责课程学员学习情况；隐藏价格、税务、订单金额 |
| 运营 | 线索、学员、业务报表和交易售后只读；强调跟进和转化入口 |
| 仓管 | 库存、供货商、采购、发货、物流配置；隐藏不必要财税和课程学习内容 |
| 客服 | 售后查询、退款审核、开票查询只读；不展示税务规则和对账代账 |
| 代账人员 | 只展示授权财税模块、收款对账、开票、红冲、代账材料；未授权模块不出现 |

## 11. 原型 PNG / HTML 转组件规范

### 11.1 使用原则

| 原型产物 | 可使用内容 | 不可使用内容 |
|---|---|---|
| PNG 截图 | 页面布局、信息层级、业务字段、状态位置、交互路径参考 | 直接按像素机械复刻、忽略响应式和组件复用 |
| HTML 导出 | 字段顺序、页面结构、局部交互说明 | 直接复制导出的临时 HTML、内联样式、绝对定位、无语义 class |
| 原型文档 | 页面范围、状态、按钮、业务流转说明 | 与接口、权限、状态枚举冲突的临时描述 |

### 11.2 抽象流程

| 步骤 | 输出物 | 说明 |
|---|---|---|
| 1. 识别页面类型 | 页面模板 | 判断是列表页、详情页、表单页、结果页、流程页、窄屏任务页 |
| 2. 提取业务字段 | 字段清单 | 对齐 API 响应字段和权限脱敏规则，缺字段不在前端硬造 |
| 3. 提取状态 | 状态标签配置 | 对齐 14 文档枚举和本文件状态色，不新增临时中文状态 |
| 4. 提取操作 | `allowed_actions` 映射 | 按权限、状态和业务对象控制按钮 |
| 5. 提取布局 | 组件组合 | 使用筛选区、表格、详情描述、单据链、弹窗、抽屉等组件拼装 |
| 6. 提取变量 | 设计 Token | 颜色、字号、间距、圆角、阴影进入设计变量 |
| 7. 形成模板 | 页面模板和组件规范 | 同类页面复用，不按原型截图逐页复制代码 |
| 8. 联调校验 | 接口和权限验收 | 使用真实或 Mock 接口返回驱动页面，而不是静态假数据 |

### 11.3 页面模板抽象

| 模板 | 组成 | 适用页面 |
|---|---|---|
| 后台列表页 | 页面标题、筛选区、主操作、表格、分页、批量操作 | 线索、课程、订单、退款、开票、发货、采购、对账、日志 |
| 后台详情页 | 标题摘要、状态概览、描述分组、明细表、单据链、操作栏 | 订单详情、退款详情、采购详情、学员详情 |
| 后台编辑页 | 分组表单、可折叠区块、上传、底部固定保存 | 课程编辑、系统配置、物流配置、税务规则 |
| 移动卡片列表 | 搜索/分段控件、卡片列表、加载更多、空状态 | 课程列表、学习中心、我的订单、采购单列表 |
| 移动详情页 | 状态概览、业务卡片、明细区、底部操作栏 | 订单详情、退款进度、物流详情、采购详情 |
