## 5. 课程与规格模型

| 模型 | 口径 |
|---|---|
| 课程 | `course` 保存标题、类型、封面、讲师、分类、课程群二维码、默认税务规则、售卖时间和状态。 |
| 规格 | `course_spec` 保存售价、原价、库存模式、是否含实物、SKU/赠品 SKU、税务规则和金额拆分快照来源。 |
| 课节 | `course_lesson_node` 支持章节/课节基础结构，直播课节必须填写开始和结束时间。 |
| 可售条件 | 小程序仅查询 `ON_SHELF`、售卖时间有效、至少一个启用规格的课程。 |
| 后续订单输入 | S5 创建订单时可从课程、规格读取课程快照、价格快照、税务规则、SKU/赠品引用。 |

## 6. 课程审批基础

| 审批类型 | 通过后状态 | 拒绝后状态 |
|---|---|---|
| `COURSE_ON_SHELF` | `ON_SHELF` | 恢复提交前状态，通常为 `DRAFT` |
| `COURSE_OFF_SHELF` | `OFF_SHELF` | 恢复提交前状态，已上架课程恢复 `ON_SHELF` |
| `COURSE_DELETE` | `DELETE_PENDING` | 恢复提交前状态，并清空本次删除截止时间 |

## 7. 线索、跟进、学员手机号合并

| 能力 | 规则 |
|---|---|
| 公开留资 | `/api/h5/lead/leads` 创建 `PUBLIC_H5` 线索，状态为 `PENDING_FOLLOW`，写系统审计。 |
| PC/企微建档 | `/api/admin/leads`、`/api/wecom/sidebar/leads` 创建线索；企微侧边栏纳入管理端登录拦截和 `crm:lead:write` 权限。 |
| 跟进 | 写 `lead_follow_record`，按 `Idempotency-Key` 幂等；首次跟进把 `PENDING_FOLLOW` 转为 `CONTACTED`。 |
| 放弃/重新跟进 | `ABANDONED` 保存放弃原因；重新跟进必须填写下次跟进时间并恢复 `CONTACTED`。 |
| 支付后线索转化 | `LeadApplicationService.convertPaidLead` 供 S5 支付成功后调用；优先匹配 `wecom_external_user_id`，其次匹配手机号；重复订单转化返回幂等命中。 |
| 手机号授权 | `phone_code=mock:<手机号>`；手机号未存在则绑定当前学员；同手机号人工学员可合并；不同 OpenID 冲突返回 `409` 并审计。 |
| 禁用处理 | `sys_user` 或 `edu_student` 非 `ACTIVE` 时拒绝登录。 |

## 8. 学习权益幂等能力

| 场景 | 规则 |
|---|---|
| 支付成功开通 | `LearningEntitlementService.openForPaidOrder` 按 `student_id + order_id + course_id` 幂等创建 `ACTIVE` 权益。 |
| 重复支付事件 | 返回原权益，不重复插入。 |
| 退款冻结 | `applyRefundEffect(..., action=FREEZE)` 把权益置为 `FROZEN`，写 `source_refund_id`，停止提醒。 |
| 退款撤销 | `applyRefundEffect(..., action=REVOKE)` 把权益置为 `REVOKED`，写 `source_refund_id`，停止提醒。 |
| 学习页限制 | 小程序课程学习页仅允许当前学员自己的 `ACTIVE` 权益访问。 |

## 10. 权限、数据范围、脱敏、审计

| 项 | 说明 |
|---|---|
| 登录拦截 | `/api/admin/**`、`/api/collab/**`、`/api/wecom/sidebar/**` 走 `AdminSecurityInterceptor`。 |
| 静态权限 | 课程、审批、线索写接口使用 `@RequirePermission` 或 `@RequireAnyPermission`。 |
| 数据范围 | 讲师只能访问负责课程；运营只能处理本人负责线索；越权拒绝并写失败审计。 |
| 字段脱敏 | 权限目录补充 `lead_mobile`，运营查询线索时手机号按权限脱敏。 |
| 审计 | 课程、规格、课节、审批、线索、跟进、手机号授权/合并/冲突、权益开通/冻结/撤销均写 `audit_operation_log`。 |
