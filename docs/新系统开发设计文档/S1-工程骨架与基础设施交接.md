| 接口 | 方法 | 说明 | 权限 |
|---|---|---|---|
| `/api/health` | `GET` | 存活检查，返回 `status`、`app_name`、`version`、`environment`、`integration_mode`、`server_time`、`trace_id`。 | 无需登录，只返回非敏感信息。 |

| 字段 | 说明 |
|---|---|
| `code` | 成功为 `OK` |
| `message` | 成功为 `ok` |
| `trace_id` | 请求链路 ID，优先使用 `X-Trace-Id` |
| `data` | 业务响应体 |
