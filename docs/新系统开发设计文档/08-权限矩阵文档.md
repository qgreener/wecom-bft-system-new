## 2. 权限表达口径

| 标记 | 含义 |
|---|---|
| 管理 | 可查看、新增、编辑、提交、处理该模块内授权动作 |
| 只读 | 可查看列表和详情，不可新增、编辑、删除、审批、导出敏感明细 |
| 负责 | 仅限本人负责课程、线索、待办或授权对象 |
| 授权 | 需叠加代账管理中配置的可见模块，未授权则不可见 |
| 财税 | 仅限财税、对账、代账所需数据，不包含线索运营和课程内容管理能力 |
| 发货 | 仅限订单中与实物履约、物流、库存扣减相关的能力 |
| 审计 | 可查看或导出审计日志，不可编辑、删除日志 |
| 无 | 无菜单入口且接口返回 `403` 或不返回该资源 |

## 3. 角色总览

| 角色 | 职责定位 | 默认数据范围 | 特别限制 |
|---|---|---|---|

## 10. 操作日志要求

| 日志项 | 要求 |
|---|---|
| 基础字段 | 操作时间、操作人、角色、IP 地址、终端、`trace_id`、操作模块、操作类型、目标类型、目标编号、结果、失败原因 |
| 变更详情 | 敏感写操作记录变更前后值；涉及密钥、手机号、税号、地址、凭证文件时只记录脱敏值或文件引用 |
| 不可变更 | 操作日志不可编辑、不可删除；只能按权限查询和导出 |
| 查询控制 | 默认仅超级管理员可见；后续如扩展审计授权角色，必须显式配置 |
| 导出控制 | 导出日志必须记录二次操作日志，包含筛选条件、导出人、导出时间和文件编号 |
| 失败记录 | 鉴权失败、数据范围拒绝、状态冲突、幂等冲突、外部回调失败均应记录可追踪摘要 |

| 必须记录日志的操作 | 具体动作 |
|---|---|
| 用户与权限 | 角色申请、审批通过或拒绝、角色分配、权限矩阵变更、账号启禁 |
| 课程与学习 | 课程新增、编辑价格或税务规则、分配讲师、上架申请、下架申请、删除申请、审批结果、直播时间调整通知 |
| 线索与学员 | 线索创建、写跟进、放弃、重新跟进、确认转化、外部联系人和学员匹配冲突处理 |
| 支付退款 | 退款审核、拒绝、重试、转人工、人工退款登记、退款凭证上传 |
| 履约库存 | SKU 新增编辑、手动入库、手动出库、确认发货、人工签收、物流异常补偿、库存校正 |
| 采购供应 | 供货商同步、编辑、停用启用、创建采购、取消采购、大额采购审批、确认收货、进项发票回填 |
| 发票税务 | 人工开票、自动开票失败处理、红冲、税务规则新增编辑停用、发票文件上传或补发 |
| 对账代账 | 上传账单、生成对账批次、标记已核对、导出差异、材料申请、材料上传、材料确认、材料下载 |
| 系统配置 | 支付配置、物流配置、开票配置、采购阈值、通知模板、Mock/沙箱/真实模式切换 |
| 文件与导出 | 发票、红冲凭证、退款凭证、代账材料上传下载，任意 Excel/CSV/PDF 导出 |

## 11. 接口落地要求

| 要求 | 说明 |
|---|---|
| 权限返回 | `/api/admin/auth/me` 必须返回 `roles[]`、`permission_codes[]`、`data_scope`、`menus[]`、`field_masks[]` |
| 菜单控制 | 前端按 `menus[]` 渲染菜单；后端仍按接口权限和数据范围做最终校验 |
| 按钮控制 | 前端按 `permission_codes[]` 控制按钮展示；写接口必须校验按钮权限、状态机和幂等键 |
| 数据范围 | 查询接口统一注入角色数据范围；无权查看的数据返回 `403` 或列表中过滤，不用前端自行过滤 |
| 字段脱敏 | 列表、详情、导出、日志统一复用 `field_masks[]`；导出不得绕过脱敏 |
| 代账授权 | 代账人员在角色权限之外必须叠加“可见模块”配置；未授权模块菜单不返回、接口不放行 |
| 讲师范围 | 讲师所有课程、学员、权益查询必须按 `teacher_user_id` 或课程负责关系过滤；不可通过学员 ID 直接越权查看 |
| 外部协同 | 企微侧边栏、供货商 H5、公开留资 H5 不作为 PC 一级菜单，但接口仍需鉴权、数据范围和日志控制 |
