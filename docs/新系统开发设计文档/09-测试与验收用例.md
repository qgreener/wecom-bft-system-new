# 09-测试与验收用例

## 1. 文档目标与依据

| 项目 | 说明 |
|---|---|
| 文档目标 | 按模块和核心链路定义测试与验收用例，覆盖正常流程、异常流程、权限校验、状态流转、副作用验证和外部接口 Mock 场景 |
| 上游依据 | `00-文档说明.md`、`01-需求规格说明书.md`、`02-业务流程与状态机说明.md`、`03-模块设计文档.md`、`06-API接口文档.md`、`07-外部系统联调文档.md`、`08-权限矩阵文档.md`、`11-关键业务规则与算法设计.md`、`12-异常处理与幂等补偿设计.md` |
| 适用范围 | PC 管理端、小程序端、企微侧边栏、供货商 H5、公开留资 H5、外部回调与 Mock 适配层 |
| 验收原则 | 订单必须拆分支付状态、履约状态、退款状态、开票状态；外部失败不得绕过状态机；主链路成功后弱依赖失败不得回滚主状态 |
| Mock 边界 | Mock 与真实平台共用接口契约、状态枚举、幂等键、回调处理链路和异常补偿入口，不增加演示专用状态 |
| 通过标准 | P0 链路全部通过；重点链路能在 Mock 环境稳定演示成功、失败、重复回调、异常待处理和人工补偿 |

## 2. 用例分类与编号

| 分类 | 编号后缀 | 覆盖重点 |
|---|---|---|
| 正常流程 | `N` | 用户按预期完成业务操作，单据、状态、通知和日志正确生成 |
| 异常流程 | `E` | 参数错误、状态冲突、外部失败、回调乱序、数据不一致等场景 |
| 权限校验 | `P` | 菜单、按钮、接口、数据范围、字段脱敏、导出权限 |
| 状态流转 | `S` | 支付、履约、退款、开票、采购、材料等状态按状态机推进 |
| 副作用验证 | `SE` | 权益、发货任务、库存流水、通知、红冲待办、对账、代账材料、操作日志 |
| Mock 场景 | `M` | 支付、退款、物流、电子发票、红冲、企微审批、通知卡片、邮件或文件发送 |

### 4.1 用户与权限

## 7. 状态流转验收清单

| 状态对象 | 必验路径 | 不允许行为 |
|---|---|---|
| 订单支付状态 | 待支付 -> 已支付；待支付 -> 已关闭 | 退款成功后把支付状态改为已关闭；已关闭订单继续支付 |
| 订单履约状态 | 无实物为无需发货；含实物支付后待发货 -> 已发货 -> 已签收 | 未支付发货；退款已成功后继续发货；重复发货重复扣库存 |
| 订单退款状态 | 无退款 -> 审核中 -> 已拒绝；审核中 -> 退款处理中 -> 已退款；审核中 -> 待人工退款 -> 已退款；退款失败 -> 退款处理中或待人工退款 | 存在进行中退款时重复申请；已退款终态被失败回调覆盖 |
| 订单开票状态 | 未申请 -> 已申请 -> 已开具；已申请 -> 待开具 -> 已开具；已开具 -> 已红冲 | 未支付开票；学员修改开票金额；用红冲替代退款 |
| 学习权益状态 | ACTIVE -> FROZEN -> REVOKED；ACTIVE -> REVOKED；FROZEN -> ACTIVE（退款拒绝或人工恢复） | 未支付开通权益；退款失败撤销权益；撤销后仍保留学习入口 |
| 采购状态 | 大额采购审批中 -> 待确认 -> 已确认 -> 已发货 -> 已完成；审批中 -> 审批拒绝；待确认 -> 已拒绝或已取消 | 审批未通过推送供货商；重复收货重复入库 |
| 材料状态 | 待补充 -> 已上传 -> 已确认；待补充或已上传 -> 已关闭 | 无文件且无系统明细时确认；关闭不填原因 |
| 异常任务 | 待处理 -> 重试成功；待处理 -> 转人工；待处理 -> 标记已处理；待处理 -> 人工关闭 | 未核对资金流水直接开放权益；关闭仍影响资金、权益、库存、发票一致性的异常 |

## 8. 验收出入口与证据要求

| 验收对象 | 需要保留的证据 | 判定标准 |
|---|---|---|
| 页面流程 | PC、小程序、企微侧边栏、供货商 H5 的关键页面截图或录屏 | 能从页面完成用例操作，状态标签和可操作按钮与权限一致 |
| 接口响应 | 请求参数、响应码、响应体、`trace_id`、幂等键 | 成功、失败、冲突、无权、异步受理返回符合接口文档 |
| 数据单据 | 订单、支付记录、退款单、权益、发货单、库存流水、发票单、采购单、对账记录、材料记录 | 单据完整且能通过订单详情或业务详情追溯 |
| 状态流转 | 状态变更前后截图、接口响应或数据库摘要 | 仅按状态机允许路径推进，不被弱依赖失败回滚 |
| 副作用 | 通知、待办、单据链、红冲待办、对账明细、代账材料、库存流水 | 关键副作用可见、可重试、可追溯 |
| 外部回调 | `integration_callback_event`、回调请求摘要、处理状态、失败原因 | 所有回调先落库再幂等处理；重复和乱序回调不重复副作用 |
| 人工补偿 | 异常待处理记录、重试记录、上传凭证、关闭原因、处理人 | 补偿动作有权限校验、前置校验和操作日志 |
| 审计日志 | `audit_operation_log` 查询结果和导出记录 | 敏感操作日志不可编辑、不可删除，敏感字段脱敏 |
