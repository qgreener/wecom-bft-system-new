# 04-领域模型与数据字典

## 1. 文档定位

| 项目 | 说明 |
|---|---|
| 文档目标 | 基于 `02-业务流程与状态机说明.md` 和 `03-模块设计文档.md` 定义新系统核心领域对象、字段、枚举、唯一约束、关联关系和生命周期 |
| 上游依据 | `00-文档说明.md`、`02-业务流程与状态机说明.md`、`03-模块设计文档.md` |
| 下游影响 | `05-数据库设计文档.md`、`06-API接口文档.md`、`08-权限矩阵文档.md`、`09-测试与验收用例.md` |
| 设计边界 | 本文件只定义领域模型和数据口径，不绑定历史数据库、不引用历史接口、不写真实密钥或真实外部平台地址 |

本文件中的“字段类型”为逻辑类型，用于统一业务含义和接口口径。后续数据库字段类型、索引名、字段长度、分表策略和审计落库方式由 `05-数据库设计文档.md` 进一步细化。

## 2. 建模原则

| 原则 | 说明 |
|---|---|
| 订单中心 | 订单是支付记录、学习权益、发货单、退款单、发票单、对账记录和代账材料的主追溯入口 |
| 状态拆分 | 订单不设置单一 `order_status`，必须拆分为支付状态、履约状态、退款状态和开票状态 |
| 子单据自治 | 支付、退款、发货、开票、采购、对账等子对象保存自身状态，订单只保存摘要状态和单据链入口 |
| 快照不可变 | 下单后价格、税务、课程规格、收货地址、发票抬头等关键快照不可被后续主数据修改反向污染 |
| 外部适配不污染模型 | 微信支付、物流、电子发票、企微和 Mock 共用正式状态、字段和幂等规则，不增加演示专用字段 |
| 业务编号可读 | 核心单据除技术主键外必须有业务编号，便于页面展示、对账、导出、审计和人工补偿 |
| 操作可审计 | 角色分配、退款、发货、采购、开票、红冲、配置修改、导入导出等敏感动作必须写操作日志 |
| 软删除谨慎 | 课程、SKU、供货商、角色等主数据可禁用或下架，已被订单引用的数据不得物理删除影响历史单据 |

## 3. 通用字段约定

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | ID | 是 | 技术主键，系统内唯一 |
| `biz_no` | String | 视对象而定 | 业务编号，如订单号、退款单号、采购单号；创建后不可修改 |
| `created_at` | DateTime | 是 | 创建时间 |
| `created_by` | ID | 否 | 创建人；系统事件创建时可为空或记录系统用户 |
| `updated_at` | DateTime | 是 | 最近更新时间 |
| `updated_by` | ID | 否 | 最近更新人 |
| `remark` | Text | 否 | 业务备注 |
| `deleted_flag` | Boolean | 否 | 仅用于允许软删除的主数据；核心交易单据默认不使用软删除 |

| 逻辑类型 | 含义 |
|---|---|
| ID | 系统内部主键或外键 |
| String | 短文本、编码、名称、外部流水号 |
| Text | 长文本说明 |
| Enum | 本文件定义的枚举值 |
| Money | 金额，后续落库建议统一按“分”保存 |
| Integer | 整数数量、排序号、次数 |
| Decimal | 税率、比例等小数 |
| Boolean | 布尔值 |
| Date | 日期 |
| DateTime | 日期时间 |
| JSON | 快照、扩展配置或结构化明细，后续数据库设计需拆分或限制结构 |
| FileRef | 文件引用，不直接保存文件二进制 |

## 4. 领域对象总览

| 模块 | 核心对象 | 说明 |
|---|---|---|
| 用户与权限 | 用户、角色 | 统一承载内部人员、学员身份、供货商访问身份和权限角色 |
| 线索与学员 | 线索、学员 | 承接留资、企微侧边栏、手机号合并、支付转化回写 |
| 课程与学习 | 课程、规格、章节课节、学习权益 | 承接课程售卖、内容组织、直播/录播安排和支付后的访问资格 |
| 交易订单 | 订单 | 作为单据链中心保存订单快照和四类摘要状态 |
| 支付退款 | 支付记录、退款单 | 承接支付回调、退款审核、原路退款、人工退款和退款副作用 |
| 履约库存 | 发货单、库存 SKU | 承接实物履约、物流轨迹、库存出入库和库存预警 |
| 采购供应 | 采购单、供货商 | 承接采购审批、供货商确认、采购物流、收货入库和进项票回填 |
| 发票税务 | 发票单 | 承接发票抬头快照、开票、人工补偿和红冲 |
| 对账代账 | 对账记录、代账材料 | 承接账单导入、差异核对、材料申请、上传确认和月度归档 |
| 通知审批 | 通知、审批 | 承接站内通知、订阅消息、企微卡片、待办和审批结果回写 |
| 系统配置与审计 | 操作日志 | 承接所有关键操作、外部回调补偿和导入导出的审计追踪 |

## 7. 核心关联关系

| 主对象 | 关联对象 | 关系 | 说明 |
|---|---|---|---|
| 用户 | 角色 | 多对多 | 一个用户可有多个角色，一个角色可授予多个用户 |
| 用户 | 学员 | 一对一 | 学员身份用户对应一个学员档案 |
| 线索 | 学员 | 多对一 | 多来源线索可归并到同一个学员 |
| 线索 | 订单 | 一对多 | 支付成功后可把订单回写到最近有效线索 |
| 课程 | 规格 | 一对多 | 一个课程可配置多个售卖规格 |
| 课程 | 章节课节 | 一对多 | 课程下有章节和课节树 |
| 规格 | 库存 SKU | 多对一 | 含实物或赠品规格引用 SKU |
| 学员 | 订单 | 一对多 | 学员可多次购买课程 |
| 订单 | 支付记录 | 一对多 | 正常一笔成功支付，异常或重试可保留多条记录 |
| 订单 | 学习权益 | 一对多 | 支付成功后按课程和规格开通权益 |

| 订单 | 发票单 | 一对多 | 正常一个有效发票单，红冲保留同一单据状态和凭证 |

| 通知 | 业务对象 | 多态关联 | 通知通过关联对象跳转业务详情 |
| 操作日志 | 业务对象 | 多态关联 | 通过目标类型和目标 ID 追溯敏感操作 |

| 供货商 | `supplier_no`、`supplier_name` | 采购和供应关系识别 |
| 对账记录 | `batch_no + record_type + merchant_order_no + external_transaction_no`、`bill_month + bill_source + file_digest` | 防止重复导入和重复对账 |
| 代账材料 | `material_no` | 材料申请和归档追踪 |
| 通知 | `notification_no`、`idempotency_key + channel + receiver_user_id` | 避免同一事件重复通知 |
| 审批 | `approval_no`、`wecom_approval_id`、`approval_type + related_object_type + related_object_id + status=PENDING` | 防止重复审批 |
| 操作日志 | `log_id` | 审计记录唯一定位 |

## 10. 幂等与快照字段口径

| 场景 | 幂等键 | 快照或补偿字段 | 说明 |
|---|---|---|---|
| 支付回调 | `merchant_order_no + external_payment_no` | `raw_callback_snapshot`、`failure_reason` | 重复成功回调不重复开通权益、发货和通知 |
| 退款回调 | `refund_no + external_refund_no` | `failure_reason`、`manual_voucher_file` | 已退款终态不得被失败回调覆盖 |
| 物流回调 | `tracking_no + logistics_node_time` | 物流轨迹明细、`exception_flag` | 重复轨迹不重复写入 |
| 开票回调 | `invoice_apply_no + invoice_no` | `invoice_file`、`failure_reason` | 自动失败转待开具 |
| 红冲回调 | `invoice_apply_no + red_invoice_no` | `red_invoice_file`、`failure_reason` | 红冲完成后不重复处理 |
| 采购入库 | `purchase_no + inbound_batch_no` | `purchase_lines`、收货记录 | 防止重复确认收货导致重复入库 |
| 对账导入 | `bill_month + bill_source + file_digest` | 原始文件摘要、差异原因 | 防止重复上传生成重复记录 |

| 快照类型 | 保存位置 | 必须包含 |
|---|---|---|
| 课程规格快照 | 订单、订单明细、学习权益 | 课程名称、规格名称、价格、讲师、课程类型、是否含实物 |
| 价格快照 | 订单、订单明细 | 原价、优惠、应付、实付、赠品、金额拆分 |
| 税务快照 | 订单、发票单 | 税务规则、税率、培训服务/教材/实物/物流拆分、税额计算口径 |
| 收货地址快照 | 订单、发货单 | 收货人、手机号、省市区、详细地址 |
| 发票抬头快照 | 发票单 | 抬头类型、抬头名称、税号、邮箱、金额 |
| 审批金额快照 | 审批、采购单 | 创建时采购阈值、采购金额、申请原因 |
