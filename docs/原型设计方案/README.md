# 原型设计方案

## 系统概要

基于企业微信的训练营营业财税一体化管理系统。系统以企业微信组织和工作台应用为入口，围绕线索获客、课程商品、订单支付、履约供应、售后退款、发票税务、代账协同、经营报表和预测分析形成业务闭环。最终毕设交付版以 PC 管理端、小程序端、企微/外部协同端三端协同为核心；企业微信优先真实接入；支付、物流、发票等外部业务接口提供标准适配层，运行环境可使用 Mock 保证完整可演示；财务软件直连作为扩展能力，当前通过导入导出支持代账协同。

范围说明：本期取消外部平台订单设计，不设计微信小店、抖店等外部销售渠道的订单同步、渠道配置和商品映射。

维护状态：原型设计方案作为需求来源和页面交互参考保留，后续不再作为唯一真相源持续维护。若原型文档与 `docs/新系统开发设计文档` 存在字段、状态、接口或部署口径冲突，以新系统开发设计文档为准。
