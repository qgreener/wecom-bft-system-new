# PC管理端页面设计

说明：PC 管理端供多角色协作使用（超管、教务、讲师、运营、仓管、客服、代账人员），完成线索管理、课程管理、库存管理、订单处理、退款审核、开票、发货、物流配置、学员管理、报表查看等后台操作。

术语映射：本原型中"物流状态"与新系统设计文档中的"履约状态"（`fulfillment_status`）为同一概念——原型侧重页面展示用语，设计文档使用系统设计术语。订单管理的筛选和标签已同时展示两种口径，开发时以设计文档为准。

## 角色划分

| 角色 | 职责 | 导航菜单 |
|------|------|---------|
| 超级管理员 | 全系统无限制，角色分配与系统配置 | 全部一级菜单 |
| 教务 | 课程创建、定价、排课、分配讲师、上架下架 | 首页、课程与履约、客户与学员（只读）、交易售后（只读）、财税与报表（只读） |
| 讲师 | 课程内容管理、创建预约直播/跳转直播入口、回放、学员查看 | 首页、课程与履约、客户与学员（仅负责课程的已购学员） |
| 运营 | 获客、日常运营、数据报表 | 首页、客户与学员、交易售后（只读）、财税与报表（业务数据） |
| 仓管 | 实物商品供应链：库存、采购、发货、物流配置 | 首页、供应与库存、交易售后（发货相关） |
| 客服 | 售后处理与学员咨询 | 首页、客户与学员（只读）、交易售后、开票管理（只读） |
| 代账人员 | 财税与代账处理，接收系统数据用于做账报税 | 首页、财税与报表、开票管理、收款对账中心 |


## 1.登录

	说明：
		PC管理端在企微工作台不设登录页，在网页端支持企业微信扫码登录
	页面：
		网页端：居中登录卡片 + 企微扫码登录入口
	交互：
			1.登录成功跳转至首页，登录失败提示错误原因
			2.若账号未分配角色，登录后跳转至申请角色页
## 2.申请角色页

	说明：
		未分配角色人员的默认页面，仅可申请角色
	页面：
		居中卡片，顶部文字"您的账号暂未分配权限"
		下方角色下拉选择（超级管理员/教务/讲师/运营/仓管/客服/代账人员）
		申请说明输入框（选填）
		底部"提交申请"按钮
	交互：
			1.选择角色并提交后，系统发起角色申请审批，所有超级管理员在企微内审批。审批通过后系统自动分配角色，审批拒绝则通知申请人（含拒绝原因）
		2.提交后页面显示"申请已提交，请等待管理员审核"
			3.超管在企微审批通过后，系统自动分配角色，用户重新登录即可进入对应首页。审批日志同时记录至操作日志

## 3.整体页面结构

	说明：
		PC端采用左右布局：左侧固定宽度导航栏 + 右侧内容区
	页面：
		左侧导航栏（深色背景，白色文字）：
		  顶部系统logo/名称
		  一级菜单：首页、客户与学员、课程与履约、供应与库存、交易售后、财税与报表、系统配置
		  二级菜单：
		    客户与学员：线索管理、学员管理
		    课程与履约：课程管理、课程编辑页
		    供应与库存：库存管理、供货商管理、采购订单、发货管理
		    交易售后：订单管理、退款处理、开票管理
		    财税与报表：数据报表、代账管理、收款对账中心
		    系统配置：物流配置、税务规则、操作日志、系统设置
		  可折叠/低频项：物流配置、操作日志默认收纳在系统配置下，不作为常驻一级入口
		  范围说明：本期取消外部平台订单设计，不设计微信小店/抖店等外部销售渠道的订单同步、渠道配置和商品映射
		右侧内容区：
		  顶部面包屑导航 + 用户头像/退出
		  下方为页面主体内容

## 4.首页

	说明：
		登录后的默认页面，展示关键数据概览
	页面：
		顶部一行六个统计卡片：
		  今日新增线索数
		  今日新增订单数
		  待处理退款数
		  待发货订单数
		  待开票申请数
		  库存预警数（低于安全阈值的SKU数）
		下方左侧：近7日订单趋势折线图
		下方右侧：近7日营收柱状图
		再下方：流程看板，顶部提供角色切换按钮（超级管理员/教务/讲师/运营/仓管/客服/代账人员），切换后展示该角色在系统内的待办任务、常用入口和业务流程节点
		流程节点筛选规则：
		  运营：待跟进线索（线索状态=待跟进）、今日待跟进（下次跟进时间≤今日）、已转化线索（线索状态=已转化）
		  教务/讲师：待上架课程（课程状态=下架）、今日直播课节（直播时间=今日）、待补回放（直播状态=已结束且无回放）
		  仓管：待发货订单（履约状态=待发货，物流待处理）、库存预警（库存低于安全阈值）、待收货采购单（采购状态=已发货）
		  客服：待审核退款（退款状态=审核中）、待处理开票（开票状态=已申请/待开具）
		  代账人员：待开票超期、采购无进项票、收款对账差异、待补充材料
	交互：
		1.点击统计卡片跳转至对应管理页（已筛选对应状态）
		2.点击流程看板中的角色按钮，切换该角色的任务视图；点击流程节点跳转至对应页面并自动带入筛选条件

## 5.线索管理

	说明：
		管理潜在学员线索，记录跟进过程，支持确认转化。线索来源两种：
		  侧边栏 — 运营在企微聊天侧边栏中一键建档，自动绑定外部联系人ID，创建人即跟进人
		  推广码落地页 — 用户扫描不同渠道推广码打开H5留资页，提交表单后自动创建，推广渠道作为独立字段记录
	页面：
		顶部一行："生成推广码"按钮（右侧）
		下面筛选栏：线索状态筛选（全部/待跟进/已联系/已转化/已放弃）+ 来源入口筛选（全部/侧边栏/推广码落地页）+ 推广渠道筛选（全部/小红书/朋友圈/公众号/抖音/其他）+ 搜索框（姓名/手机号）
		下方为线索表格，列：
		  姓名
		  手机号
		  外部联系人ID
		  来源入口（侧边栏/推广码落地页，彩色标签）
		  推广渠道（侧边栏显示"-"，推广码落地页显示渠道名称）
		  来源明细（侧边栏显示创建人，推广码落地页显示推广码名称）
		  意向课程（选填）
		  线索状态（待跟进/已联系/已转化/已放弃，彩色标签）
		  最近跟进时间
		  操作：跟进、确认已转化、放弃、查看详情
		底部分页器
		线索状态说明：
		  待跟进：新建线索尚未产生有效跟进记录
		  已联系：已记录至少一次跟进，但尚未转化
		  已转化：已关联或生成正式学员记录
		  已放弃：明确无购买意向或无法继续触达
	交互：
		1.点击"跟进"弹出跟进记录弹窗：跟进方式（电话/微信/面谈）+ 跟进内容 + 下次跟进时间，保存后线索状态自动从待跟进→已联系
		2.点击"确认已转化"：系统根据手机号或外部联系人ID检查是否已关联学员且存在已支付订单；若存在，则线索状态→已转化；若不存在，则提示"未匹配到已购学员，暂不可确认转化"
		3.小程序端在购买/下单前需授权手机号，拒绝授权则无法继续交易；线索与学员通过手机号或外部联系人ID自动关联，PC端不再提供手动转学员流程
		4.点击"查看详情"查看线索完整信息和历史跟进记录
		5.点击"放弃"弹出确认弹窗：选择放弃原因（无意向/价格不合适/联系不上/其他）+ 备注，确认后线索状态→已放弃；已放弃线索仍可在详情页点击"重新跟进"恢复为已联系
		6.点击"生成推广码"弹出推广码管理弹窗：
		  上半部分：已有推广码列表，每条显示推广码名称+渠道+创建时间，操作：下载二维码、复制链接、删除
		  下半部分："新建推广码"按钮 → 展开表单：推广码名称（必填）+ 渠道（小红书/朋友圈/公众号/抖音/其他）→ 确认后生成落地页链接和二维码图片，加入上方列表
		  用户通过推广码提交的线索自动标记来源入口=推广码落地页，推广渠道记录为该推广码配置的渠道

## 6.课程管理

	说明：
		查看、搜索、管理所有课程
	页面：
		顶部一行：搜索框 + 课程类型筛选（全部/直播课/录制课）+ "新增课程"按钮（右侧）
		下方为课程表格，列：
		  课程封面缩略图
		  课程名（可点击）
		  类型（直播/录制）
		  价格（最低规格价）
		  状态（上架/下架/审批中/待删除）
		  操作列：编辑、申请上架/申请下架、删除
		底部分页器
		讲师视图：只显示负责课程，操作为内容维护、创建预约直播、跳转直播入口、同步直播状态、补充回放、查看学员；不显示价格、税务规则、上架/下架、删除等管理操作
	交互：
		1.搜索框支持课程名模糊搜索
		2.点击"新增课程"跳转至课程编辑页（空表单）
		3.点击课程名或"编辑"跳转至课程编辑页（带已有数据）
			4.点击删除弹出确认弹窗，填写删除原因并确认后发起审批（课程名+删除原因）。超管审批通过后课程进入"待删除"状态，系统先生成已购学员站内课程删除通知；学员已授权订阅消息时同步发送，3天后正式删除；审批拒绝则恢复原状
		5.点击"申请上架/申请下架"弹出申请弹窗，填写原因后发起审批；审批通过后上架/下架正式生效，审批拒绝则保持原状态，审批中不允许重复提交

## 7.课程编辑页

	说明：
		新增或编辑课程信息（共用同一页面）
	页面：
		顶部标题：新增课程 / 编辑课程
		基本信息区：课程名（必填）、课程封面（图片上传）、课程类型（直播课/录制课，单选）、课程详情（富文本编辑器）、负责讲师（下拉多选，从讲师角色账号中选取）、上架状态（当前状态展示 + 上架/下架申请按钮）
			售卖规格区（可折叠）：添加规格按钮，每行固定四列：规格名 | 价格 | 税务规则/金额拆分 | 包含实物（多选，从库存SKU中选取，可设定数量；无则留空）。课程价格由最低规格价自动确定。税务规则用于确定开票内容、税率和税额计算口径。规格可选择单一税务规则，也可配置混合规格金额拆分。示例：录播基础班499元=培训服务499元；直播训练营1299元=培训服务1299元；训练营教材包1599元=培训服务1399元+教材资料200元；训练营实物礼盒1999元=培训服务1699元+教材资料200元+实物赠品100元。规格可增删改，支持拖拽排序
			赠品区（可折叠）：添加按钮，每行一个赠品：赠品名 + 数量 + 税务处理方式（促销成本/随主课开票/单独作为实物赠品）。所有售卖规格共享同一赠品列表
		课程群区（可折叠）：只维护课程群编号、二维码配置状态、入群二维码图片。若未配置，显示"上传入群二维码"按钮；课程群由教务或运营在线下/企微中手动创建，系统不负责自动建群
		讲师内容区（讲师角色可编辑）：章节/小节标题、直播时间、回放链接、课程资料；价格、税务规则、上架状态、删除课程等字段仅管理员/教务可编辑
			课程安排区（可折叠）：添加章节按钮，每个章节：章节名 + 可展开的小节列表。小节行内容：小节名+类型（直播/录制，由课程类型继承但可单独覆盖）。直播小节额外显示：直播时间（日期+时:分）+直播状态标签（未开始/已预约/直播中/已结束/回放就绪）+操作按钮（创建预约直播/进入直播/同步状态/补充回放）。录制小节额外显示：回放链接（已上传后显示）+操作按钮（上传回放）。支持拖拽排序
			底部固定"保存"按钮
	交互：
		1.保存时校验必填项
		2.富文本编辑器支持图文混排
		3.图片上传成功后展示预览和文件名
		4.章节/小节支持拖拽调整顺序
		5.保存成功后返回课程管理页并刷新列表
			6.编辑已有课程时，若修改了直播课的小节时间，保存后弹窗提示是否通知已购学员，确认后生成站内课程时间调整通知；学员已授权订阅消息时同步发送
			7.点击小节的"创建预约直播"按钮：创建预约直播记录或获取企微直播入口，不直接控制企微开播；直播状态由企微回调或人工同步更新为直播中/已结束
			8.点击"进入直播"：跳转企微直播入口；若回调未及时返回，讲师可在结束后手动同步状态并补充回放链接
			9.点击"补充回放"：弹出输入框填写回放链接（已结束但无回放时显示）
			10.直播课小节保存后，系统记录直播时间，到期前N小时生成站内开课提醒；学员已授权订阅消息时同步发送

## 8.库存管理

	说明：
		管理课程配套实物商品的库存（SKU），支持商品类目、入库、出库、库存预警
	页面：
		顶部一行：搜索框（商品名）+ 类目筛选 + "商品类目管理"按钮 + "新增入库"按钮
		商品类目管理弹窗：类目列表（类目名称、说明、启用状态、关联SKU数），操作：新增、编辑、停用
		下方为库存表格，列：
		  SKU编号
		  商品名
		  商品类目
			  供货商（关联的供货商名称）
		  当前库存数量
		  安全库存阈值（低于此值预警）
		  最近入库时间
		  最近出库时间
		  操作：入库、出库、编辑、出入库记录
		底部分页器
		低于阈值的行高亮红色背景
	交互：
		1.点击"新增入库"弹出入库弹窗：商品名+入库数量+备注 → 确认后库存增加，记录入库日志
		2.点击"入库"弹出同上弹窗
		3.点击"出库"弹出出库弹窗：出库数量+关联订单（选填）+备注 → 确认后库存减少，记录出库日志
		4.点击"出入库记录"弹窗显示该SKU的历史出入库明细列表
		5.发货成功时自动扣减对应SKU库存；发货失败时内部状态回滚，外部物流或打印已产生结果的情况进入异常待处理，由仓管人工补偿
		6.库存扣减后若低于安全阈值，系统生成库存预警待办和企微通知卡片，仓管可从首页或库存管理进入处理
			7.低于阈值的行操作列显示"补货"按钮 → 点击跳转至采购订单页并预填该SKU的供货商和商品信息


## 9.供货商管理

	说明：
		管理上游实物商品供货商，采购订单可推送给供货商进行确认和回填。供货商来源仅支持从企微上下游同步形成候选列表，不支持手动录入
	页面：
		顶部一行："同步企微上下游供货商"按钮
		下方为供货商列表，每条显示：
		  供货商名称
		  企微企业标识（用于上下游消息推送）
		  对接人（显示姓名/手机号；底层可绑定企微成员标识）
		  供应商品（关联的SKU列表，标签展示）
		  状态（合作中/已停用）
		  操作：编辑、停用/启用
		底部分页器
	交互：
		1.点击"同步企微上下游供货商"弹窗：选择上下游企业 → 选择该企业下的对接人 → 选择供应商品（多选，从库存SKU中勾选）→ 确认后创建或更新供货商
		2.页面展示联系人姓名，技术侧保存可用于消息触达的成员标识
		3.编辑可修改供应商品关联和对接人

## 10.采购订单

		4.结算单有记录但系统无订单，标记为未匹配；系统有已支付订单但结算单无记录，也标记为未匹配
		5.代账人员核对无误后可点击"标记已核对"，记录核对人、核对时间和备注

## 22.代账管理

	说明：
		配置代账人员在 PC 管理端内可见的财税与代账模块。代账人员通过管理端工作台获取经营数据用于做账报税，仅能操作被授权的代账相关功能
	页面：
		代账人员选择（从管理员账号中筛选代账人员，可多选）
		管理端可见模块（多选勾选）：月度快报、收入明细、退款明细、成本归集、采购支出、待开票、开票汇总、增值税销项、税负概览、收款对账中心
		保存权限按钮
	交互：
		保存后，被选中的代账人员登录 PC 管理端时仅看到已授权的代账相关模块
		模块权限变更记录至操作日志

	代账工作台（PC 管理端内页面，按角色与可见模块控制）：

	管理端向代账人员提供：
		Tab「月度快报」：本月营收、退款总额、采购支出、已开票金额四卡片 + 趋势图
		Tab「收入明细」：已支付订单列表（编号、学员、课程、金额、支付时间），日期筛选 + 导出Excel
		Tab「退款明细」：已退款记录列表（退款单号、原订单、金额、时间、原因），日期筛选 + 导出Excel
		Tab「成本归集」：按成本类型汇总展示采购成本、物流费用、讲师课酬、广告投放、支付手续费，可手动录入或导入成本资料，支持按月份筛选并导出Excel
		Tab「采购支出」：已完成采购单列表（单号、供货商、金额、完成时间、发票状态），日期筛选 + 导出Excel
		Tab「待开票」：学生已申请未开具的发票列表（订单编号、抬头、金额、接收邮箱），每行操作：填写发票号码+上传发票图片/PDF → 标记已开具 → 生成小程序站内开票成功通知；学员已授权订阅消息时同步发送。日期筛选 + 导出Excel
		Tab「开票汇总」：已开具发票列表（订单编号、抬头、金额、开具时间、接收邮箱），支持上传发票文件后发送至接收邮箱，日期筛选 + 导出Excel
		Tab「增值税销项」：按订单关联的税务规则汇总已开具发票的销项税（月份 | 订单编号 | 开票金额合计 | 税率 | 税额 | 发票份数），税额按含税金额拆分计算：税额=含税金额÷(1+税率)×税率；税率取订单课程/规格快照。若规格为混合商品，则先按规格内金额拆分为培训服务、教材资料、实物商品、物流等明细，再分别按各自税务规则计算税额并汇总。日期筛选 + 导出Excel
			Tab「税负概览」：当月销项税、进项税（已收供货商发票金额×税率）、应纳税额（销项-进项）、税负率（应纳税额/营收×100%）。仅作经营参考，不作正式税务申报依据
		Tab「收款对账中心」：上传微信支付结算单/交易账单 → 系统按商户订单号自动逐笔匹配 → 显示订单金额/结算金额/手续费差额/到账时间 → 未匹配行高亮标记 → 导出差额汇总
		Tab「材料申请」：代账人员可向管理员申请补充材料，字段包括材料类型、用途说明、截止时间、关联月份/订单/采购单；提交后向管理员推送待办，管理员上传资料后代账人员可查看和下载

	需要代账人员提供（代账人员 → 系统）：
		每月微信支付结算单/交易账单（从微信支付商户平台导出），上传至收款对账中心用于自动比对
		对账确认（比对准后标记某月已核对，备注异常说明）
